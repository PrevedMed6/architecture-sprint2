# pymongo-api

## Как запустить

Запустить mongodb в режиме шардирования и приложение

```shell
docker compose up -d
```

Заполняем инициализируем mongodb с шардированием и заполняем данными

```shell
./scripts/mongo-init.sh
```
Скрипт выполняет следующие операции:
1. инициализирует сервис конфигурации configSrv
2. инициализирует шарды shard1 и shard2
3. инициализирует роутер mongos_router и создает тестовые данные
4. демонстрирует количество документов в шардах

## Как проверить

Откройте в браузере http://localhost:8080
